Use git_review.

Yêu cầu:

1. Chạy git.git_status.
2. Chạy git.git_diff_unstaged.
3. Không git add.
4. Không git commit.
5. Không git push.
6. Final bằng tiếng Việt:
- status summary
- diff summary
- risky changes nếu có
- suggested commit message

Không sửa file.
Chỉ trả JSON tool call hoặc JSON final.
